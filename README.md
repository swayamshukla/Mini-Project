# 🎓 B.Tech Journey

A personal 4-year B.Tech progress tracker — day counter, daily planner,
visual journey map, progress dashboard, and goals/milestones.

## Run it

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Notes

- Data (tasks, goals, milestones, your start/graduation dates) is saved
  in your browser's `localStorage`, so it persists between visits on the
  same browser/device.
- On first run, demo data is seeded automatically — open **Settings**
  (gear icon) to set your real B.Tech start date and expected graduation
  date.
- Icons: [lucide-react](https://lucide.dev). Styling: Tailwind CSS +
  custom design tokens in `src/App.jsx`.
